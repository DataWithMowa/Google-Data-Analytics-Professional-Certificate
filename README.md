## Course Summaries & Key Learnings

### Course 1: Foundations: Data, Data, Everywhere
In this course, I learned the foundations of data analytics, including:
*   What data analytics is
*   The data life cycle and the data analysis process
*   How data analysts use data to support decision-making
*   Common tools used by data analysts, including spreadsheets, SQL, R, and Tableau

**Major Key Learning:** Fairness in Data Analytics. 
*(Note: More details can be found in my Course 1 notes).*

### Course 2: Ask Questions to Make Data-Driven Decisions
*   **Spreadsheets:** Explored functions, formulas, and using Google Sheets for reports and visualization.
*   **Communication:** Learned how to communicate effectively with stakeholders (executives, customer-facing teams, and data scientists).
*   **Business Acumen:** Covered the scope of work, statements of work, and how to ask effective questions to make data-driven decisions.
*   **Overall:** Explored how to use quantitative and qualitative data, metrics, and math to connect the dots, alongside structured thinking and key communication skills.

### Course 3: Prepare Data for Exploration
*   **Tools:** Google Sheets and BigQuery.
*   **Concepts:** Learned about data types, identifying bias in data, and how to organize and protect data using spreadsheets and SQL.
*   **Focus Areas:** Data responsibility, database essentials, and data security, ensuring data quality and confidence in analysis.

### Course 4: Process Data from Dirty to Clean
*   **Data Integrity:** Learned the importance of checking data for integrity and how to handle sampling bias.
*   **Cleaning Techniques:** Practiced cleaning "dirty" data using spreadsheets and SQL queries.
*   **Verification:** Learned how to verify data cleaning results and write effective data cleaning reports.
*   **Career Prep:** Focused on building an effective resume that highlights data analytics strengths and relevant experience.

### Course 5: Analyze Data to Answer Questions
*   **Organizing Data:** Learned the importance of sorting and filtering to organize data for effective analysis.
*   **Formatting:** Converted and formatted data to get it ready for analysis.
*   **Aggregation & Calculations:** Used functions, syntax, and SQL queries to aggregate data from multiple tables and perform complex calculations.

### Course 6: Share Data Through the Art of Visualization
*   **Data Visualization:** Learned how to use visualizations to communicate data insights and results.
*   **Tableau:** Explored Tableau as a powerful data visualization tool to create dashboards and filters.
*   **Data Storytelling:** Discovered how to craft compelling, data-driven narratives and effective presentations.
*   **Presentation Skills:** Learned best practices for Q&A sessions and how to address data limitations during presentations.
