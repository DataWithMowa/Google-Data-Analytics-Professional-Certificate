# Google Data Analytics Professional Certificate

Completed through the **Wetech Inc. Data Analytics Track**.

The certificate provided practical exposure to **data cleaning, analysis, visualization, spreadsheets, SQL, Tableau, and Python** through hands-on learning, assessments, and real-world case studies.

---

## Course 1: Foundations: Data, Data, Everywhere

### Overview

In this course, I learned the foundations of data analytics, including:

* What data analytics is
* The data life cycle
* The data analysis process
* How data analysts use data to support decision-making
* Common tools used by data analysts, including spreadsheets, SQL, R, and Tableau

### Tools Learned

#### Google Sheets

* Data entry
* Sorting and organizing data
* Formulas
* Data visualization

#### SQL

* Introduction to working with data using SQL
* Understanding how SQL can be used to explore and analyze data
